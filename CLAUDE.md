# Working on this repository

The design record, the implementation pitfalls and the build log live in
[`DESIGN.md`](DESIGN.md). **Read it before changing anything** — Section 2 is the design,
Section 3 is the list of mistakes each rule is built to avoid, Section 5 has the invariants
that are bugs rather than trade-offs if broken, and Section 6 is what exists today.

This file exists so the design record is picked up automatically by tooling that looks for
`CLAUDE.md`. It is a pointer, not a second copy — there is only one design document.
